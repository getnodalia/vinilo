## **Español**

### Correcciones
- Buscar actualizaciones ya no termina en «Could not reach GitHub Releases: http status: 403». GitHub solo responde unas pocas consultas por hora desde cada red, compartidas por todas las apps que la usan. Ahora Vinilo guarda la última lista de versiones y, al volver a buscar, solo pregunta si ha cambiado, una pregunta que no gasta ese límite. Vale para Linux y para Vinilo Nodalia en Mac.
- Si el límite se agota igualmente, Vinilo sigue sabiendo cuál es la versión más nueva y ofrece abrir su página.
- Los errores del actualizador se leen en tu idioma, con qué ha pasado y cuándo volver a intentarlo, en lugar del mensaje técnico en inglés.
- Descargar una actualización ya no se corta a mitad (por ejemplo al 75 %) con «timeout: receive body». Si la conexión se para, la descarga sigue desde donde se quedó en lugar de empezar de cero.

## **English**

### Fixes
- Checking for updates no longer ends in "Could not reach GitHub Releases: http status: 403". GitHub answers only a few requests an hour from each network, shared by every app on it. Vinilo now keeps the last list of releases and, when it checks again, only asks whether it changed, a question that does not spend that limit. This applies to Linux and to Vinilo Nodalia on Mac.
- If the limit runs out anyway, Vinilo still knows which version is newest and offers to open its page.
- Updater errors read in your language, saying what happened and when to try again, instead of a technical message in English.
- Downloading an update no longer stops part way (at 75 %, say) with "timeout: receive body". If the connection stalls, the download carries on from where it stopped instead of starting over.
